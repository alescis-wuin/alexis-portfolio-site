# P2.4-F — viewer média natif

Statut : implémenté sur `feature/p2.4-projects-redesign` après P2.4-E.

## Objectif

P2.4-F ajoute une lecture agrandie des preuves visuelles sans dépendance externe et sans changer le schéma média v5. Le comportement repose sur le `<dialog>` natif du navigateur afin de conserver des primitives modales standard : top layer, inertie du document et gestion native de `Escape`.

## Contrat généré

Chaque média d'une étude de cas — hero, diagramme d'architecture et galerie — est rendu comme un lien direct vers le fichier source avec `data-media-viewer-trigger`. Le lien reste fonctionnel sans JavaScript et constitue le chemin de progressive enhancement.

Un seul `<dialog data-media-viewer>` est généré par page projet. À l'ouverture, le viewer reprend :

- l'URL du média ;
- son texte alternatif ;
- ses dimensions déclarées ;
- sa légende ;
- son type `data-media-kind`.

Le type contrôle le titre annoncé : `Capture produit agrandie` pour `screenshot`, `Schéma technique agrandi` pour `diagram`.

## Interaction et accessibilité

`assets/js/main.js` n'intercepte que le clic primaire sans touches modificatrices. Ctrl/Cmd/Shift/Alt conservent donc le comportement normal du lien.

Quand le navigateur supporte `HTMLDialogElement.showModal()` :

- activation souris ou clavier ouvre le dialogue modal ;
- le focus initial est placé sur le bouton de fermeture ;
- le bouton de fermeture ferme explicitement le viewer ;
- `Escape` utilise le comportement natif du dialogue ;
- un clic sur la zone transparente autour du panneau ferme le viewer ;
- le scroll du document arrière est bloqué pendant l'ouverture ;
- la fermeture restitue le focus au média déclencheur ;
- le bouton de fermeture mesure au moins 44 × 44 px ;
- `prefers-reduced-motion: reduce` retire la transition de l'indication d'agrandissement.

Si `<dialog>` modal n'est pas disponible, aucun comportement JavaScript alternatif n'est injecté : le lien média reste utilisable directement.

## Responsive

Le dialogue occupe la top layer du viewport et centre un panneau borné. L'image utilise `object-fit: contain`, avec une hauteur maximale calculée depuis `100svh`. Le panneau devient plus compact sous 720 px et reste sans débordement horizontal sur la matrice mobile / desktop / ultrawide.

## Validation

P2.4-F ajoute :

- une assertion générateur sur les liens de progressive enhancement et le `<dialog>` unique ;
- des tests QA statiques sur le contrat JS/CSS/HTML ;
- des E2E Playwright pour ouverture, type de média, fermeture, `Escape`, restitution du focus et géométrie mobile ;
- deux captures reproductibles du viewer Alycia ouvert (`mobile`, `full-hd`).

La matrice visuelle passe de 51 à 53 captures.

## Hors périmètre

P2.4-F ne change ni les médias, ni le schéma v5, ni les contenus éditoriaux. P2.4-G reste responsable de la passe finale responsive, accessibilité et performance du redesign P2.4.
