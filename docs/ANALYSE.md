# Analyse du portfolio

## Positionnement retenu

Positionnement principal : développeur backend et concepteur d'applications.

Le site évite de réduire le profil à Java. Java reste visible car il structure plusieurs projets, mais la proposition de valeur est plus large : API, bases de données, logique métier, architecture, automatisation, applications desktop et pipelines applicatifs.

## Sources utilisées

- CV fourni : objectif d'alternance, parcours, expériences, projets, compétences, bénévolat et projet d'impact.
- Profil GitHub : README de profil, dépôts publics Streamfolio, Solvia, Aelia.
- Page LinkedIn : lien conservé, mais le contenu de la page n'a pas pu être vérifié depuis l'environnement de recherche au moment de la génération.

## Choix de contenu

### Mis en avant

1. Streamfolio : projet le plus démonstratif pour backend web, sécurité, streaming, données, Docker, tests et CI.
2. Solvia : projet le plus démonstratif pour modélisation métier, architecture applicative et application local-first.
3. Ludani : différenciation technique avec moteur 2D/3D et rendu temps réel.
4. Alycia : veille IA locale, agents, workflows et automatisation.
5. Aelia : attention à l'accessibilité desktop, JavaFX, tests et CI.

### Retiré des pages HTML publiques

- Âge.
- Téléphone.
- Mention RQTH.

Ces informations restent dans le CV PDF fourni. Elles sont plus sensibles et moins nécessaires à la lecture d'un portfolio public.

## Message principal

Le site cherche à prouver une capacité à construire des applications complètes et maintenables, pas seulement à lister des technologies.
