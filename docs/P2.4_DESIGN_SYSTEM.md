# P2.4-B - Design system and base project identity

Status: implementation contract.

## Scope

This phase establishes the visual substrate defined by P2.4-A without doing the later layout
rewrite.

Included:

- semantic foundation tokens for future frame/content/reading widths;
- five project identities driven by `data-project-slug`;
- per-project colors plus non-color motifs;
- stronger, media-first project cards;
- branded detail-page masthead and media framing;
- generated detail pages expose their slug on `<body>`;
- generator and E2E regression coverage.

Deferred:

- P2.4-C: wide/ultrawide layout and 12/16-column restructuring;
- P2.4-D: editorial restructuring of project case-study sections;
- P2.4-E: new screenshots, diagrams and typed-media schema decision;
- P2.4-F: native `<dialog>` image viewer;
- P2.4-G: final responsive/accessibility/performance QA.

No `data/projects.json` schema change is allowed in this phase.

## Foundation tokens

- `--frame-max: 175rem`
- `--content-max: 112rem`
- `--reading-max: 72ch`
- `--wide-reading-max: 86ch`
- `--gutter: clamp(1rem, 2.6vw, 4rem)`
- `--section-space: clamp(4.5rem, 8vw, 9rem)`
- project tokens:
  - `--project-accent`
  - `--project-accent-2`
  - `--project-glow`
  - `--project-pattern-image`
  - `--project-pattern-size`

The frame/content tokens are introduced now but the existing layout is not migrated to them until
P2.4-C.

Color is decorative and never the only carrier of state or meaning.

## Accessibility rules

- all content text keeps the existing semantic text colors;
- project colors are used mainly for borders, rails, glows and low-opacity surfaces;
- no state is identified by color alone;
- motion is disabled for the new card transforms under `prefers-reduced-motion: reduce`;
- generated DOM order is unchanged;
- no new dependency or JavaScript interaction is introduced.

## Detail-page contract

Each public generated page has:

```html
<body data-project-slug="streamfolio">
```

The generator owns this attribute. It must never be manually edited in generated HTML.

## Card contract

Existing `data-project-slug` on project cards remains the source of identity. CSS maps each slug to
its tokens, so design data is not duplicated inside `data/projects.json`.

## Validation

- schema remains v4;
- Solvia remains unpublished and has no generated public page;
- all five public detail pages expose the correct body slug;
- project-card CSS defines the P2.4-B media-first identity layer;
- the full strict test suite remains green.
