# Contrats historiques P2.3–P2.5

Ces tests sont conservés pour retracer la version initiale. Ils imposaient notamment le rail latéral, le parallaxe, une sélection précise de quatre projets, des formulations textuelles et des grilles devenues incompatibles avec la nouvelle conception.

Ils ne sont plus exécutés. Leurs chemins relatifs correspondent à leur emplacement d’origine dans `tests/qa/` ou `tests/e2e/`.

La suite active conserve les tests du générateur, des médias, des filtres mobiles et de la visionneuse. `tests/e2e/signature.spec.mjs` contrôle les parcours, les liens, le CV, la navigation clavier, l’absence de JavaScript, les filtres combinés, le presse-papiers, le reflow, la réduction du mouvement et axe sur toutes les pages. `tests/qa/signature.test.mjs` couvre les réserves de publication, les budgets des CSS chargées et les garde-fous éditoriaux.
