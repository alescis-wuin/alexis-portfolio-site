# Personnalisation rapide

## Changer la date de disponibilité

Dans `index.html`, chercher :

```txt
à partir d’octobre 2026
```

et remplacer par la date exacte.

## Changer l'e-mail

Dans `index.html`, les pages `projets/*.html` et `assets/js/main.js` si nécessaire, chercher :

```txt
alexis.guinot@onsiea.com
```

## Ajouter une capture projet

Remplacer les fichiers SVG dans :

```txt
assets/img/projects/
```

Conserver le même nom de fichier ou modifier le `src` dans les pages HTML.

## Changer les couleurs

Modifier les variables CSS dans :

```txt
assets/css/styles.css
```

Les variables principales sont : `--bg`, `--surface`, `--text`, `--muted`, `--accent`, `--accent-2`.
