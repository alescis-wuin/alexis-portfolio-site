# P2.5-E - clôture responsive, accessibilité et QA du profil

Statut : implémentée sur `feature/p2.5-profile-redesign` après P2.5-D.

## Objectif

P2.5-E ferme la phase P2.5 sans ajouter de nouvelle fonctionnalité éditoriale. Le lot transforme les critères de sortie des cinq sections profil en garde-fous reproductibles : ordre sémantique, navigation de section, reflow, absence d'overflow, navigation clavier du contact, taille des cibles principales, reduced motion, contraste des tokens structurants, budgets de performance et matrice visuelle complète.

Les sections concernées restent :

1. Compétences ;
2. Expérience ;
3. Formation & trajectoire ;
4. À propos / méthode ;
5. Contact.

## Matrice responsive finale

Les E2E dédiés au profil parcourent la page d'accueil sur :

- `320x720` — reflow ;
- `390x844` — mobile ;
- `768x1024` — tablette portrait ;
- `1024x768` — tablette paysage ;
- `1366x768` — laptop bas ;
- `1920x800` — desktop large et bas ;
- `1920x1080` — Full HD ;
- `2560x1080` — ultrawide ;
- `3440x1440` — ultrawide large ;
- `3840x2160` — 4K.

Pour chaque profil, le document et les cinq sections doivent rester sans overflow horizontal. Les blocs structurants de P2.5 — capacités, cartes d'expérience, blocs de formation, étapes de méthode et liens de contact — doivent rester contenus dans le viewport.

## Accessibilité de clôture

P2.5-E consolide les contrats introduits par P2.5-A à P2.5-D :

- ordre DOM stable : compétences, expérience, formation, méthode, contact ;
- chaque section conserve un `aria-labelledby` pointant vers son titre visible ;
- les liens de navigation de section conservent leurs ancres canoniques ;
- l'e-mail principal puis LinkedIn, GitHub et le CV suivent un ordre clavier prévisible ;
- les quatre cibles de contact conservent une hauteur minimale de 44 px ;
- le focus visible reste fourni par le contrat CSS global `:focus-visible` ;
- avec `prefers-reduced-motion: reduce`, les blocs `data-reveal` du profil sont immédiatement visibles, sans translation résiduelle, et le défilement fluide global est désactivé ;
- les tokens de texte principaux (`--text`, `--muted`, `--muted-2`, accents) conservent un contraste AA d'au moins 4.5:1 face aux fonds structurels `--bg` et `--surface` ;
- le contraste `--accent-contrast` / `--accent` reste lui aussi supérieur ou égal à 4.5:1.

Les tests n'essaient pas de remplacer une revue humaine exhaustive WCAG. Ils verrouillent les invariants qui peuvent être vérifiés de manière déterministe dans le dépôt et le navigateur.

## Performance

P2.5-E conserve les budgets statiques établis par P2.4-G. `npm run validate:performance` et `npm run check:strict` restent les garde-fous canoniques. La clôture P2.5 ne relève aucun budget et n'ajoute aucune dépendance runtime.

## QA visuelle finale

Avant P2.5-E, chaque section profil était capturée sur quatre profils : reflow 320, mobile, Full HD et 4K. La clôture étend les cinq scènes du profil aux huit profils visuels canoniques :

- `reflow-320` ;
- `mobile` ;
- `laptop-low` ;
- `desktop-low` ;
- `full-hd` ;
- `ultrawide` ;
- `ultrawide-large` ;
- `4k`.

Cette extension ajoute 20 captures et fait passer la matrice globale de **81 à 101 captures**.

## Critère de sortie P2.5

P2.5 est considérée fermée lorsque les contrôles suivants sont tous verts sur le même working tree :

1. QA ciblée P2.5-E ;
2. `npm run check:strict` ;
3. `npm run capture:visual` avec `101/101` captures ;
4. `git diff --check` ;
5. revue du périmètre Git avant commit.

P2.5-E ne modifie ni les faits publiés, ni la hiérarchie éditoriale des lots A à D, ni les interactions du portfolio. Toute évolution de contenu ou de fonctionnalité après cette clôture appartient à une phase distincte.
