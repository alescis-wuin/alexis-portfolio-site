# Checklist de validation avant publication

## Contenu

- [ ] Vérifier l'orthographe des noms de projets.
- [ ] Vérifier la date de début d'alternance.
- [ ] Vérifier l'e-mail de contact.
- [ ] Vérifier que le CV PDF est la version publique voulue.
- [ ] Ajouter des captures réelles des projets si disponibles.

## Accessibilité

- [ ] Tester la navigation au clavier.
- [ ] Vérifier le focus visible sur tous les liens et boutons.
- [ ] Tester le menu mobile.
- [ ] Tester thème clair et thème sombre.
- [ ] Tester avec l'option système « réduire les animations ».
- [ ] Lancer Lighthouse ou PageSpeed Insights.
- [ ] Lancer un audit axe DevTools si possible.

## Déploiement

- [ ] Mettre à jour `sitemap.xml` si le domaine change.
- [ ] Mettre à jour `robots.txt` si le domaine change.
- [ ] Garder ou supprimer `CNAME` selon l'hébergement choisi.
- [ ] Vérifier les chemins des liens après déploiement.
