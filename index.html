05 / Ce qui m’anime

Comprendre
les rouages.

Ce qui m’intéresse dans un projet, c’est le lien entre ses parties. Comment une vidéo arrive jusqu’au lecteur. Comment deux interfaces partagent la même logique. Comment une décision d’architecture se traduit dans le code.

Je pars du problème, je découpe, j’essaie, puis je vérifie.

Cette curiosité dépasse le logiciel : je m’intéresse aussi à l’électronique, aux sciences et à la botanique.

À plus long terme, je souhaite poursuivre ma formation vers l’intelligence artificielle et l’ingénierie des systèmes d’IA.

  1. 01

    Partir de l’usage

    Qui va s’en servir ? Avec quelles données et quelles contraintes ? Le besoin donne la direction.

  2. 02

    Donner une place à chaque pièce

    Interface, métier, données, intégrations : rendre les responsabilités et les dépendances explicites.

  3. 03

    Faire fonctionner un premier parcours

    Un écran, une API ou un flux concret pour confronter les choix à leur fonctionnement réel.

  4. 04

    Laisser de quoi vérifier

    Des tests utiles, des commandes reproductibles et les limites connues, pour pouvoir reprendre le travail.
