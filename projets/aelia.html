Application météo desktop · Prototype

Aelia

Application météo JavaFX avec fournisseur simulé, données météo/air/UV/pollen, thème sombre, contraste renforcé et contrôles clavier.

Desktop Accessibilité Architecture
Voir le dépôt GitHub Télécharger le CV

Problème

Ce que le projet cherche à résoudre

Préparer une application desktop extensible autour de fournisseurs météo, en conservant testabilité, accessibilité et séparation des ports/adaptateurs.

Stack

Java 21 JavaFX AtlantaFX Maven Tests GitHub Actions

Fonctionnalités

Points techniques principaux

  • Structure JavaFX MVC avec port orienté fournisseur.
  • Fournisseur local simulé pour météo, qualité de l’air, UV et pollen.
  • Requêtes de valeurs courantes et abonnements live configurables.
  • Tables de limites API et de données supportées.
  • Contrôles compatibles clavier, tooltips et métadonnées d’accessibilité JavaFX.
  • Build Maven, tests unitaires et workflow GitHub Actions.

Preuve de compétence

Ce que ce projet démontre

  • Conception extensible par contrat d’adaptateur.
  • Attention à l’accessibilité dès le prototype.
  • Industrialisation avec tests et CI.
