Plateforme de streaming vidéo · Finalisé

Streamfolio

Application web de streaming vidéo avec authentification, catalogue, administration média, upload, streaming MP4/HLS et pipeline FFmpeg.

Backend Full-stack Données DevOps
Voir le dépôt GitHub Télécharger le CV

Problème

Ce que le projet cherche à résoudre

Créer une plateforme portfolio proche d’un produit réel : accès sécurisé, expérience vidéo fluide, administration des médias et chaîne de traitement fiable.

Stack

Spring Boot PostgreSQL Redis MinIO Docker HLS Playwright

Fonctionnalités

Points techniques principaux

  • Authentification avec Spring Security, BCrypt, cookies HttpOnly/SameSite et sessions Redis.
  • Catalogue films/séries avec recherche, filtres, watchlist et progression de lecture.
  • Streaming HTML5 : MP4 progressif, HTTP Range, WebVTT et HLS via hls.js.
  • Administration média : upload, métadonnées, miniatures, publication et relance de jobs.
  • Pipeline asynchrone : file persistante, retry exponentiel, reprise après redémarrage et annulation FFmpeg.
  • Persistance PostgreSQL/Flyway, stockage objet MinIO et environnement Docker reproductible.
  • Tests Maven, tests sécurité, streaming/admin, smoke tests, E2E Playwright et CI GitHub Actions.

Preuve de compétence

Ce que ce projet démontre

  • Architecture applicative complète, pas seulement une interface.
  • Sensibilité aux contraintes backend : sécurité, sessions, stockage, files et robustesse.
  • Capacité à documenter les décisions techniques et les limites du projet.
