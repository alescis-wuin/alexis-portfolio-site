Suivi patrimonial local-first · En cours

Solvia

Application local-first de suivi patrimonial : comptes, actifs, positions, snapshots, flux financiers, valorisation et indicateurs de performance.

Backend Desktop Données Architecture
Voir le dépôt GitHub Télécharger le CV

Problème

Ce que le projet cherche à résoudre

Suivre des données financières personnelles en séparant clairement les valeurs saisies, les flux d’argent et les calculs de performance.

Stack

Java Spring Boot JavaFX PostgreSQL Flyway REST Maven

Fonctionnalités

Points techniques principaux

  • Comptes, enveloppes, actifs, positions, snapshots et flux financiers.
  • Historique de patrimoine net, graphiques par période et agrégations personnalisées.
  • Architecture Maven multi-module : domaine, application, persistance, backend, desktop.
  • API REST validée, documentation OpenAPI statique et persistance PostgreSQL/Flyway.
  • Interface desktop JavaFX/AtlantaFX et posture local-first sans télémétrie externe.

Preuve de compétence

Ce que ce projet démontre

  • Modélisation métier et découpage applicatif.
  • Fiabilité des calculs et séparation des responsabilités.
  • Capacité à concevoir une application métier maintenable.
